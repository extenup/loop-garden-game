# Loop Garden — public web build

Wordless one-finger adventure by extenup: run circles around grumpy blobs to turn them into flowers.

- Play: https://extenup.github.io/loop-garden-game/
- Privacy: https://extenup.github.io/loop-garden-game/privacy.html

This is the SDK-free standalone build (no ads, no analytics, progress in browser storage only). Portal builds with their SDKs are packaged separately.
